# 设计

- 沿用 SettingsControl.xaml 的原控件、范围和文案，不增加窗口或保存按钮。
- browser.json 保存搜索设置，与各站点关键词历史共用原持久化路径，旧配置缺项使用 8 / 25 / false 默认值。
- 主进程校验设置；历史去重置顶、按站点隔离、严格遵守容量上限。参考 SearchSession.SaveKeywords 有超过上限一条的边界问题，本批按界面“最大数量”的语义实现，记录此差异。
- 全部缩略图加载、详情请求和重试共用当前主窗口加载队列，设置调低后等在途工作结束再补充，切页丢弃未开始的旧页任务。
- 隐藏已浏览仅在 renderer 过滤当前页展示，不改变 VisualPage、真实分页和筛选计数；切换立即重新展示当前页。
- 清除历史仅清除所有站点的关键词，不清理已读 ID 或登录会话。
