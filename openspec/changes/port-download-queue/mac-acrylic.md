# Mac 毛玻璃对照优化

## Scope
- 用户于 2026-09-16 授权继续对照优化 Mac 毛玻璃；仅调整 Mac 活动态染色并接通原有毛玻璃开关，不扩展其他软件设置，不改变布局。
- 保留原版失焦回退颜色、Windows 活动态染色和噪点资源。

## Evidence / Decision
- 六组同时对照固定同一红蓝背景、文字和条纹：原配置；只换 sidebar；只把页面染色降到 0.12；换材质并降染色；再开透明窗口；原材质开启透明窗口。
- 所有对照固定活动状态及同一暗色主题，避免焦点状态影响结果。
- 系统整屏截图显示：改材质或 transparent 不是主要差异；降低页面叠加染色后背景色与模糊明显。选择最小改动：保留 under-window，Mac 活动态 tint 从 0.6 改为 0.12。浏览区白底和原版布局不改。
- 单窗口截图会丢失背景合成，不能用于判断实际玻璃透明效果。使用系统“预览→截屏→从整个屏幕”检查优化后真实应用：红蓝底色柔和透出，背后的文字/条纹被模糊，前景控件清晰。

## Implementation
- [x] Mac 仅在活动且原生材质已启用时降低 tint；关闭或失焦仍使用原回退色。
- [x] 原“显示亚克力毛玻璃效果”复选框接通受限 IPC，保存到 browser.json。
- [x] 主窗口、已打开预览和后续新预览同步；重启恢复。
- [x] Mac 系统 prefersReducedTransparency 生效时关闭原生材质、保留用户启用偏好，系统限制解除后重新应用。
- [x] nativeBlur 依据材质应用结果/系统限制更新；它仍不是屏幕像素检测器，不声称能自动证明视觉成功。
- [x] Windows 沿用原有 AccentPolicy，开关禁用时使用 Disabled；拖动钩子不再重启已关闭的材质。

## Verification
- [x] Mac 开关实际调用 setVibrancy(null / under-window)。
- [x] 主/预览同步、输入边界、预览不得修改设置、关闭后重启记忆。
- [x] 模拟系统降低透明度 getter，验证关闭及恢复；没有修改实际系统设置。
- [x] 活动 tint=0.12，失焦回退不透明；原有布局/下载回归保留。
- [x] 系统整屏的原配置/优化配置视觉检查。
- Windows 原生开关分支未在 Windows 实机运行；原版 WPF 材质的逐像素比较未验证。

Implemented and verified. 用户已授权提交并继续下一阶段。
