# 实现约束

- 主进程持有下载快照、路径、队列与文件流；渲染端只提交当前条目 key、类型和有限命令，不接受任意下载 URL 或目标文件路径。
- 复用当前 Electron session、站点域名与重定向验证；原图 Referer 为详情地址，预览使用站点首页。下载采用独立 500 秒超时、最多 3 次请求尝试，不受预览 40 MiB 内存限制。
- 默认目录为系统图片目录/MoeLoaderE，默认模板 `%site %id %title` / `%site\\%title`，默认同名跳过；目录选择通过系统对话框。保存设置不影响已经入队任务。
- 下载先流式写入唯一 .part 文件，成功后独占发布目标，失败/取消清理本次临时文件，任何竞态都不覆盖已有完整文件。
- 停止/删除立即取消；重试等旧流清理完毕后以新控制器运行；失败组图不报告全组成功。静态组图及前 N 张在下载引擎验证，Konachan-G 本身无组图响应；其他站点的动态解析/后处理随站点阶段迁移。
- 兼容 .mlpub v1 schema，导出合并按站点+URL 去重；导入仅接受已迁移的 Konachan-G HTTPS 地址，文件内容限 8 MiB，不接受导入包中的本地绝对路径。保留有效的导入文件名，避免路径穿越。
- 差异明确记录：修正源重试复用已取消 token、组图失败汇总、自动改名第 3 个文件路径错误；模板别名 %upid 和 %uploader_id 均支持，按完整 token 替换避免 %site 吃掉 %sitedispname；分类反斜杠跨平台转换。源直接写最终文件改为安全临时文件提交。
- 主窗口关闭/应用退出存在未完成任务时给出导出后关闭、直接关闭、取消；导出取消/失败不退出。macOS 关闭主窗口并确认后停止队列，应用再激活仍可查看并重试。

- UI 以参考结构为准：顶部软件设置浮层，无新增侧栏工具栏/模态弹窗/保存按钮；拖入导入，右键菜单导出。后续阶段配置仅复现入口与布局，操作须明确提示未迁移，不持久化虚假状态。
