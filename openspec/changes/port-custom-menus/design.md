# 设计

- 动态分类覆盖静态 Categories，按源配置列表顺序抓取 PageUrl（默认 HomeUrl），过滤首页链接和“首页”。菜单规则复用已实现的 XPath 变换，生成首页/后续页 URL 时保留页码占位符。
- 所有请求沿用自定义站点 Session、代理和主机限制；生成模板在使用前验证。最多 16 个菜单源、总计 100 分类；总加载时限 40 秒。
- 与源启动即加载不同，本批在首次选择或搜索该站点时加载，成功缓存至退出；失败清除等待缓存可重选站点重试。原分类下拉框显示加载/失败状态，不新增窗口或按钮。
- 加载完成后一次提交整份分类，切走站点不会把迟到结果应用到其他站点。搜索等待同一加载任务，并在返回后检查取消。
- 测试按影响范围执行：动态分类/原自定义站点定向回归和类型检查，不跑全量。
