# 动态分类验收

源对照：CustomSite.AddCat、CustomLv2MenuItem，摘要见 source-hashes.json。

## 已实现

- Menus、标题/URL XPath、PageUrl 默认主页、FirstApi/FollowApi、后续页替换、OverridePagePara。
- 分类按菜单源和节点顺序生成；过滤主页链接/“首页”，保留 URL 页码占位符直到搜索时替换。
- 同一站点请求共享菜单加载任务，成功缓存；失败不提交部分分类且可重选重试；UI 切站使用序号隔离迟到结果。
- 搜索等待加载结果并检查取消，复用本站 Session、代理、HTML 限额和主机白名单。
- 分类下拉框承载加载/失败状态，不新增窗口或按钮。

## 差异与未验收

与源启动时加载不同，本批按首次选择/搜索加载，减少未使用站点的启动请求；成功缓存到退出。源逐节点捕获部分错误，本批主机验证或菜单源失败时整体报错，不展示半份分类。菜单名称去除首尾空白。

当前为可控 HTML 样本验收，用户实际 JSON/真实网站、Windows 实机仍未验收。网页登录及第三级详情不在本批。本批尚未提交。
