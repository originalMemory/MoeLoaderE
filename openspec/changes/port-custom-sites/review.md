## 明确边界与差异

使用指南见 docs/custom-sites.md。网页登录、动态分类、第三级详情、NSFW 模式及多值文本尚未迁移，包含这些能力的配置会明确失败。

源 OverrideSearchApi 的判断分支没有真正使用覆盖值，本批按字段含义生效。相对 URL 使用标准 URL 解析；currentDir 仍以页面所在目录组合。外部 CDN 需要可推导主机或 AllowedHosts；不放开任意资源域名。

源自定义 ID 为 0，本批不改变显示/命名，内部已读用详情 URL 摘要并保存最近 10000 条。详情组图先解析完整再下载（最多 100 页/5000 张，解析总时限 120 秒），与源按需展开不同；仅下载前 N 张不减少解析请求。

没有实际用户配置/真实自定义站点账号验收，也未在 Windows 实机运行；Pixiv 真实登录仍按用户决定留到 Windows。本批未提交。

HTML 解析依据：[jsdom 文档](https://github.com/jsdom/jsdom)，采用默认不执行脚本、不加载子资源的模式。原字段基线见 source-hashes.json。
