## Why

第一阶段只有启动占位页。第二阶段需要按 MoeLoaderP 当前工作区转写主界面、搜索与预览，形成一个真实站点的浏览闭环，并建立可复用的对照验收方式。

## What Changes

- 用源主界面的布局、资源、文案和交互替换占位页；覆盖首次搜索前后状态、缩略图列表、分页、选择和状态栏。
- 首站选择原项目已有的 Konachan-G（`KonachanNetSite`，`https://konachan.net`），复用其继承的 Konachan 请求与解析语义；联网可用性在实施时验证。
- 转写关键词搜索、参数、提示、过滤、已读状态与图片详情；保留源项目的取消、失败和分页行为。
- 转写独立预览窗口、图片缩放与拖动、详情展示和 Escape 关闭。
- 按原布局保留后续功能入口；下载、登录、完整设置等未实现功能明确提示未完成，不显示虚假的成功状态。
- 增加受限 preload API、主进程站点请求和图片传输，以及输入边界验证。
- 本阶段不实现下载队列、账号登录、其他站点、完整设置迁移、安装包；对应能力仍在后续阶段交付，不从项目范围删除。

## Capabilities

### New Capabilities

- `booru-browser`: 与源项目一致的单站点搜索、图片浏览、选择、分页与独立预览，以及安全的进程通信。

### Modified Capabilities

无。第一阶段 speclite 保留原路径。

## Impact

- 修改 `src/main/`、`src/renderer/`，新增实际所需的 preload、共享数据类型和站点模块；更新构建、安全策略和测试。
- 源基线包含 HEAD `f37c511` 之上的未提交修改；实施前记录相关文件摘要，不能只迁移 Git 提交版本。
- 继续使用 HTML/CSS/TypeScript 和现有 Electron 工具链；不预建通用插件框架或额外后端。
- 复用源资源或转写代码时一并保留 GPLv3 许可证及来源说明。
- Windows 做源画面与新画面对照；macOS 缺少实机验证时明确记录。
